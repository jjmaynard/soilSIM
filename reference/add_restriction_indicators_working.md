# Add Restriction Indicators (Working Version)

Adds restriction analysis exactly as in working code plus
unsuitable_horizon flag

## Usage

``` r
add_restriction_indicators_working(ssurgo_data, verbose = FALSE)
```

## Arguments

- ssurgo_data:

  SSURGO data frame with restriction data

- verbose:

  Logical; provide progress messages

## Value

Data frame with restriction indicators and unsuitable horizon flags
