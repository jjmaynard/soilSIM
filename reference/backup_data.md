# Backup Data

Creates versioned backups of important data files.

## Usage

``` r
backup_data(source_path, backup_dir = NULL, max_backups = 5)
```

## Arguments

- source_path:

  Source file path

- backup_dir:

  Backup directory (NULL = same directory)

- max_backups:

  Maximum number of backups to keep

## Value

Backup file path
