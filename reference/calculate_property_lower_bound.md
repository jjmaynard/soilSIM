# Calculate Property Lower Bound

Calculates appropriate lower bound for property ranges.

## Usage

``` r
calculate_property_lower_bound(
  row,
  property_name,
  learned_ranges,
  context_ranges,
  property_config
)
```

## Arguments

- row:

  Data frame row

- property_name:

  Property name

- learned_ranges:

  Learned ranges from data

- context_ranges:

  Contextual ranges

- property_config:

  Property configuration

## Value

Lower bound value
