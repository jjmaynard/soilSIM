# Compute Stratified Correlations

Compute correlation matrices stratified by a grouping variable

## Usage

``` r
compute_stratified_correlations(data, properties, stratify_by, methods, config)
```

## Arguments

- data:

  Input data

- properties:

  Properties to correlate

- stratify_by:

  Grouping column

- methods:

  Correlation methods

- config:

  Configuration

## Value

Stratified correlation results
