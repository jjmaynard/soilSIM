# Convert Depth Units

Converts depth measurements between different units (cm, m, in, ft).

## Usage

``` r
convert_depth_units(depths, from_unit, to_unit, round_digits = 2)
```

## Arguments

- depths:

  Numeric vector of depth values

- from_unit:

  Source unit ("cm", "m", "in", "ft")

- to_unit:

  Target unit ("cm", "m", "in", "ft")

- round_digits:

  Number of decimal places for rounding

## Value

Converted depth values
