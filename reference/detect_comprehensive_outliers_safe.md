# Safe Outlier Detection

Safe Outlier Detection

## Usage

``` r
detect_comprehensive_outliers_safe(data, properties, config, verbose = FALSE)
```

## Arguments

- data:

  Input data.

- properties:

  Character vector of properties to check.

- config:

  Analysis configuration.

- verbose:

  Logical; provide detailed progress messages.

## Value

`list(property_outliers=, summary=)`.
