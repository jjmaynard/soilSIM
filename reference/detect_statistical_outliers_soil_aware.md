# Statistical Outlier Detection (Soil-Aware)

Property-specific outlier detection that respects soil science ranges.

## Usage

``` r
detect_statistical_outliers_soil_aware(values, df, property_name)
```

## Arguments

- values:

  Numeric vector to analyze

- df:

  Full dataframe for context

- property_name:

  Property being analyzed

## Value

List with outlier detection results
