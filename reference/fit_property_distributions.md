# Fit Property Distributions

Fit Property Distributions

## Usage

``` r
fit_property_distributions(values, property_name, config)
```

## Arguments

- values:

  Property values

- property_name:

  Property name

- config:

  Configuration

## Value

Fitted distributions with quality metrics
