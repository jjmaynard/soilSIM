# Generate SSURGO Cache Key

Creates a unique cache key based on download parameters.

## Usage

``` r
generate_ssurgo_cache_key(aoi_wkt, properties, include_restrictions)
```

## Arguments

- aoi_wkt:

  Area of interest WKT

- properties:

  Vector of properties

- include_restrictions:

  Logical for restriction data

## Value

Character string cache key
