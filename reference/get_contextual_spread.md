# Get Contextual Spread

Returns property-specific contextual spread based on soil
characteristics.

## Usage

``` r
get_contextual_spread(
  row,
  property_name,
  context_ranges,
  property_config,
  bound_type
)
```

## Arguments

- row:

  Data frame row

- property_name:

  Property name

- context_ranges:

  Contextual ranges

- property_config:

  Property configuration

- bound_type:

  'lower' or 'upper'

## Value

Contextual spread value
