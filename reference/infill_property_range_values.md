# Infill Property Range Values

Infills missing \_l and \_h values using data-driven approaches and
pedological knowledge, excluding unsuitable horizons.

## Usage

``` r
infill_property_range_values(df, property_name, property_config)
```

## Arguments

- df:

  Input data frame

- property_name:

  Name of the property

- property_config:

  Property configuration list

## Value

Data frame with infilled range values
