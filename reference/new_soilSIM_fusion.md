# Multi-source raster fusion result

Wraps the list returned by
[`run_fusion()`](https://jjmaynard.github.io/soilSIM/reference/run_fusion.md)
/
[`run_fusion_group()`](https://jjmaynard.github.io/soilSIM/reference/run_fusion_group.md).

## Usage

``` r
new_soilSIM_fusion(x)
```

## Arguments

- x:

  A list produced by a fusion orchestrator.

## Value

An object of class `soilSIM_fusion`.
