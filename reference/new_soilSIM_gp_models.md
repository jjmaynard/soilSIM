# Stratified GP depth-model set

Wraps the list returned by
[`fit_depth_gp_models()`](https://jjmaynard.github.io/soilSIM/reference/fit_depth_gp_models.md).

## Usage

``` r
new_soilSIM_gp_models(x)
```

## Arguments

- x:

  A list produced by
  [`fit_depth_gp_models()`](https://jjmaynard.github.io/soilSIM/reference/fit_depth_gp_models.md).

## Value

An object of class `soilSIM_gp_models`.
