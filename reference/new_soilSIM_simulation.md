# Monte Carlo simulation result

Wraps the list returned by
[`simulate_monte_carlo()`](https://jjmaynard.github.io/soilSIM/reference/simulate_monte_carlo.md).
Nothing about the contents changes; the class only adds
`print`/`summary`.

## Usage

``` r
new_soilSIM_simulation(x)
```

## Arguments

- x:

  A list produced by the Monte Carlo engine.

## Value

An object of class `soilSIM_simulation`.
