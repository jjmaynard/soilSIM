# Descriptive-statistics result

Wraps the list returned by
[`analyze_soil_statistics()`](https://jjmaynard.github.io/soilSIM/reference/analyze_soil_statistics.md).

## Usage

``` r
new_soilSIM_statistics(x)
```

## Arguments

- x:

  A list produced by
  [`analyze_soil_statistics()`](https://jjmaynard.github.io/soilSIM/reference/analyze_soil_statistics.md).

## Value

An object of class `soilSIM_statistics`.
