# Locate the low/median/high indices and probabilities within a percentile probability vector.

Locate the low/median/high indices and probabilities within a percentile
probability vector.

## Usage

``` r
percentile_index(probs)
```

## Arguments

- probs:

  Numeric probability vector.

## Value

`list(lo_idx=, p50_idx=, hi_idx=, p_lo=, p_hi=)`.
