# Evaluate a fitted Beta quantile function on \\\[0,1\]\\

Evaluate a fitted Beta quantile function on \\\[0,1\]\\

## Usage

``` r
quantile_beta(fit, q)
```

## Arguments

- fit:

  A fit with `shape1`/`shape2` (e.g. from
  [`fit_beta_mle_newton()`](https://jjmaynard.github.io/soilSIM/reference/fit_beta_mle_newton.md)).

- q:

  Vector of probabilities.
