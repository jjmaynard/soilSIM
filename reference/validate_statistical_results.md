# Validate Statistical Results

Validate Statistical Results

## Usage

``` r
validate_statistical_results(
  correlation_analysis,
  distribution_analysis,
  outlier_analysis,
  property_statistics,
  config
)
```

## Arguments

- correlation_analysis:

  Correlation results

- distribution_analysis:

  Distribution results

- outlier_analysis:

  Outlier results

- property_statistics:

  Property statistics

- config:

  Configuration

## Value

validation results
